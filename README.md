# UnlockMethod · LSPosed test module

**Purpose:** When a lock-screen notification is tapped, try to leave the lock screen visible so the already-active UDFPS fingerprint mechanism can unlock the device instead of forcing the pattern bouncer.

**Security:** It does NOT fake a successful fingerprint, bypass primary authentication, change StrongAuth, alter lockout or modify the fingerprint HAL. When compatibility checks cannot be verified, it leaves SystemUI untouched.

## Build and install

1. Open **Actions > Build LSPosed APK**, select **Run workflow** (also runs on pushes).
2. Download the `UnlockMethod-test-APK` artifact and install `app-debug.apk`.
3. Enable it in LSPosed; scope to **System UI (com.android.systemui)** only.
4. Reboot, lock phone, tap a notification and try fingerprint unlock.

The repo is **public**. The APK uses the **temporary Android Gradle debug signing key generated by CI**; no private signing keys are committed. This key changes on a fresh GitHub runner, so to install a later build you may need to uninstall the old module APK first (then re-enable the module). For a permanently stable signature, use a private keystore stored only in GitHub Actions Secrets or sign the APK privately on your machine.

## Logs and rollback

LSPosed logs: search `NotifFingerprint:` for `loaded` and `held lockscreen`.
If notifications do not open, if SystemUI crashes, or if fingerprint does not appear: disable the LSPosed module and reboot.

## Compatibility limitations

Experimental and untested on your particular PixelOS Android 17 build. Newer SceneContainer/Compose flows may not match these methods, resulting in no change. Blocking the primary bouncer may leave an app launch pending on some ROMs; test before relying on it.

The repository contains only publicly distributable source and no passwords, keys or device-specific information.
